# Paperlogy (페이퍼로지)

문서 브랜드의 한글 글꼴이에요.

| 파일 | 굵기 (CSS `font-weight`) |
|---|---|
| `Paperlogy-1Thin.ttf` | 100 |
| `Paperlogy-2ExtraLight.ttf` | 200 |
| `Paperlogy-3Light.ttf` | 300 |
| `Paperlogy-4Regular.ttf` | 400 |
| `Paperlogy-5Medium.ttf` | 500 |

- 만든 사람: 이주임(PT&). 글자는 Gmarket Sans와 Montserrat를 바탕으로 다시 그렸어요. 웹: www.freesentation.blog/paperlogyfont
- 라이선스: SIL Open Font License 1.1 (`OFL.txt`). 문서·PDF에 넣어도 되고, 글꼴 파일을 함께 나눠도 돼요.
  글꼴 파일만 따로 팔 수는 없어요.
- 파일 안의 굵기 값은 Thin과 ExtraLight가 둘 다 250이라, CSS에서는 위 표처럼 굵기를 직접 정해서 써요.
- SemiBold(600) 이상의 굵기는 아직 없어요.
