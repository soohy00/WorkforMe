# 시각화 문서 (차트)

숫자와 그래프가 중심인 문서에 쓰는 차트 부품이에요. 문서 스타일(`document.css`)과 같이 써요.
HTML에서는 마우스를 올리거나 Tab으로 옮기면 값이 보이고, PDF에서는 그대로 인쇄돼요.

- `viz.css` — 차트 색, 범례, 툴팁, 표 보기, 숫자 카드의 작은 추세선
- `charts.js` — 차트를 그리는 코드(외부 라이브러리 없음)
- `gallery.html` — 모든 부품 견본 (가상 수치)
- 문서 견본: `../samples/weekly-dashboard.html` (주간 운영 지표)

```html
<link rel="stylesheet" href="../document.css">
<link rel="stylesheet" href="../viz/viz.css">
…
<figure class="viz" data-chart="line">
  <figcaption><span class="viz-title">주별 노쇼 비율</span><span class="viz-sub">최근 8주 · 단위 %</span></figcaption>
  <script type="application/json">
    {"x": ["8/3", "8/10"], "series": [{"name": "노쇼 비율", "values": [8.9, 9.4], "slot": 1}],
     "unit": "%", "target": {"value": 8, "label": "목표 8%"}, "note": "정의: … 출처: …"}
  </script>
</figure>
…
<script src="../viz/charts.js"></script>
```

## 무엇을 쓸까 (형태를 먼저, 색은 마지막)

| 보여 줄 것 | 쓰는 부품 | 쓰지 않는 것 |
|---|---|---|
| 숫자 하나 (+ 추세) | 숫자 카드 `.stat` + `svg.spark` | 막대 하나짜리 그래프 |
| 목표까지 얼마나 | 숫자 카드 + `.bar` | 조각 2개짜리 원 그래프 |
| 시간에 따른 변화 | `line` (목표선 `target`) | 축 두 개짜리 그래프 |
| 한 시리즈가 주인공 | `line` 또는 `hbar` + `emphasis` (나머지는 회색) | 8가지 색 |
| 항목끼리 크기 비교 | `bar`(세로), 이름이 길면 `hbar`(가로) | 값에 따라 진해지는 색 |
| 전체 중 나눔 | `stacked` (`percent: true`면 100%) | 원 그래프로 비슷한 값 비교 |
| 기준보다 위·아래 | `diverge` (위 파랑, 아래 빨강) | 가운데에 색이 있는 색 띠 |
| 항목이 7개를 넘음 | 표, 또는 표 + 그래프 | 색 더 만들기 |

**축은 하나만** 써요. 단위가 다른 두 숫자는 그래프 두 개로 나눠요.

## 색 (검사를 통과한 순서)

| 순서 | 색 | 값 | 비고 |
|---|---|---|---|
| 1 | 브랜드 초록 | `--accent` (`#00b48a`) | 회사 색으로 바꾸면 이 칸만 바뀜 |
| 2 | 주황 | `#eb6834` | |
| 3 | 파랑 | `#2a78d6` | |
| 4 | 노랑 | `#eda100` | |
| 5 | 초록 | `#008300` | |
| 6 | 분홍 | `#e87ba4` | |
| 7 | 보라 | `#4a3aa7` | |
| 8 | 빨강 | `#e34948` | |
| 회색 | 강조하지 않는 시리즈, "기타" | `#b4b4b4` (`"slot": "muted"`) | |

- 흰 바탕 기준 색약 검사: 이웃한 색끼리 ΔE 10.7(기준 8 이상), 일반 시력 ΔE 28.2(기준 15 이상).
  점 그래프처럼 모든 색이 서로 붙을 수 있는 그래프는 1–3번만 써요(모든 쌍 검사 통과).
- 1·4·6번은 흰 바탕 대비가 3:1보다 낮아요. 그래서 차트마다 **값 글자와 표 보기**를 꼭 둬요.
- 색은 순서대로 쓰고, 같은 대상은 문서 전체에서 같은 색을 써요(`slot`으로 고정). 9번째 색은 만들지 않아요.
- 글자에는 시리즈 색을 쓰지 않아요. 색은 선·막대·점에만 써요.
- 좋음·나쁨은 색만으로 말하지 않아요. 숫자 카드의 변화는 `▲ ▼`와 글로 쓰고, 색은 좋아졌는지(`good`)
  나빠졌는지(`bad`)를 따라요(올라간 방향이 아니라).
- 회사 브랜드 색으로 바꾸면 검사를 다시 돌려요:
  `node <dataviz>/scripts/validate_palette.js "<1번>,#eb6834,#2a78d6,…" --mode light --surface "#ffffff"`

## 그리는 규칙

- 선은 2px, 끝점은 지름 8px에 흰 테두리 2px. 시리즈가 하나면 아래를 10% 색으로 칠해요.
- 막대는 24px 이하, 값 쪽 끝만 4px 둥글게. 붙은 막대 사이는 2px 틈(테두리를 그리지 않음).
- 격자선은 실선 1px 회색. 점선은 쓰지 않아요.
- 범례는 시리즈가 2개 이상일 때만. 값 글자는 골라서 붙여요(끝 값, 막대 끝). 끝 글자가 겹치면 붙이지 않고 범례에 맡겨요.
- 막대 안 글자는 들어갈 때만 넣고, 바탕색에 따라 검정·흰색 중 대비가 높은 쪽을 써요.
- 모든 차트에 **표로 보기**가 있어요. 인쇄에도 표를 넣으려면 `"table": "print"`.
- 차트 아래 `note`에 **정의와 출처**를 써요. 정의 없는 숫자는 넣지 않아요(문서 규칙과 같음).
- 제목·설명·차트를 같은 쪽에 두려면 `<section class="keep">`로 묶어요.

## 문서 틀

시각화 문서도 보고서 틀(`writing-style.md`)을 따라요: 보고 요지 → 핵심 지표(숫자 카드) → 추이·분해(차트) → 건의 →
향후 계획 → 확인 요청 사항 → 관련 문서. 차트는 근거이고, 결론과 건의는 글로 써요.

## 만들기

```bash
NODE_PATH=$(npm root -g) node brand/tools/render.js <문서.html> <문서.pdf> [미리보기.png]
python3 brand/tools/bundle.py <문서.html> <문서-한파일.html>   # CSS, 글꼴, charts.js를 한 파일에
```

PDF는 화면에서 그린 차트를 그대로 인쇄해요. 툴팁과 표 보기 버튼은 인쇄되지 않아요.
