# 노션 템플릿

문서 종류 6가지의 노션 템플릿이에요. 섹션 순서와 말투는 HTML·PDF 레이아웃(`brand/layouts/README.md`)과
글쓰기 규칙(`writing-style.md`)과 같아요. 템플릿에는 회사 정보가 없어요. 회사 문서는 노션에서 이 템플릿을
복제해 쓰고, 이 저장소에는 넣지 않아요.

| 파일 | 종류 | 섹션 순서 |
|---|---|---|
| `templates/1-상사보고-결정요청.md` | 상사·대표 보고 | 보고 요지 → 배경 → 현황과 영향 → 검토 → 건의 → 향후 계획 → 확인 요청 사항 → 관련 문서 |
| `templates/2-제안서.md` | 제안서 | 승인 요청 → 문제와 이유 → 방법 → 범위 → 기대 효과(추정) → 비용·일정·사람 → 위험과 대응 → 다른 방법 → 관련 문서 |
| `templates/3-협업정렬.md` | 협업 정렬 문서 | 한 줄 요약 → 왜 하나요 → 정해진 것·열린 것·정할 것 → 범위 → 화면 상태 → 완료 기준 → 질문 창구 → 관련 문서 |
| `templates/4-투자사보고.md` | 투자사 보고 | 요약 → 핵심 숫자 → 지난번 약속과 결과 → 잘 안 된 것과 대응 → 다음 목표 → 부탁 → 관련 문서 |
| `templates/5-회의자료.md` | 회의 자료 | 일시·진행 → 이 회의가 끝나면 → 이미 정해진 것 → 안건 → 결정할 안건 → 회의 뒤 할 일 |
| `templates/6-운영문서.md` | 운영 문서 | 시행일·담당·범위 → 한 줄 요약 → 절차 → 누가 무엇을 → 예외와 승인자 → 개정 이력 → 관련 문서 |

템플릿마다 맨 위에 **작성 안내** 상자가 있어요. 쓰는 방법을 적은 상자라서, 보내기 전에 지워요.

## 문서 데이터베이스

문서는 데이터베이스 하나("문서")에 모아요. 칸은 아래와 같아요.

| 칸 | 종류 | 값 |
|---|---|---|
| 제목 | 제목 | "[결정 요청] …"처럼 무엇을 요청하는지 |
| 종류 | 선택 | 상사·대표 보고, 제안서, 협업 정렬, 투자사 보고, 회의 자료, 운영 문서 |
| 등급 | 선택 | 공개(회색), 사내한정(초록), 대외비(주황), 극비(빨강). 애매하면 고르지 않고 물어요 |
| 상태 | 선택 | 템플릿, 작성 중, 검토 요청, 승인, 수정 필요 |
| 받는 사람 | 텍스트 | 이름 직함 |
| 작성자 | 사람 | |
| 결정 기한 | 날짜 | 요청한 결정이나 회신의 기한 |
| 버전 | 숫자 | 1부터 |
| 작성일 | 만든 시간 | 자동 |

보기(view): 기본 표, **템플릿**(갤러리, 상태 = 템플릿), **진행판**(상태별 보드), **기한**(결정 기한 달력).
진행판과 기한은 템플릿 줄을 빼고 보여 줘요.

템플릿 줄의 **등급은 비워 두었어요**. 문서마다 정하고, 애매하면 고르지 않고 확인을 요청해요.

## 브랜드를 노션에 맞추기

노션에서는 글꼴과 색을 마음대로 바꿀 수 없어요. 그래서 아래처럼 맞춰요.

| HTML·PDF | 노션 |
|---|---|
| `.lead` (보고 요지, 승인 요청, 요약) | 📌 초록 바탕 콜아웃 |
| `.proposal` (건의) | ✅ 색 없는 콜아웃 |
| `.callout.info` / `warn` / `danger` | ℹ️ 파랑 / ⚠️ 노랑 / ⛔ 빨강 바탕 콜아웃 |
| 작성 안내 | ✍️ 회색 바탕 콜아웃 (보내기 전에 지움) |
| 등급 배지 | 데이터베이스 "등급" 칸 |
| Paperlogy 글꼴 | 노션 기본 글꼴 (바꿀 수 없음) |

## 노션에 넣는 방법

**A. Claude가 노션 연결로 만들기** (회사 노션이 연결된 경우)

```bash
python3 brand/tools/notion_md.py brand/notion/templates/1-상사보고-결정요청.md
```

이 명령은 템플릿을 노션 블록 형식(콜아웃, 표)으로 바꿔요. Claude는 이 결과로 페이지를 만들어요.

**B. 직접 가져오기**

1. 노션의 **가져오기(Import)** 메뉴에서 **텍스트 및 Markdown**을 고르고, `templates/` 파일을 고릅니다.
2. 가져온 문서에서 인용(>) 상자는 콜아웃이 아니에요. 상자를 콜아웃으로 바꾸고 싶으면
   블록 메뉴에서 **전환 > 콜아웃**을 눌러요. 그다음 위 표대로 색을 골라요.

**데이터베이스 템플릿으로 쓰기** (선택)

노션 연결(API)로는 데이터베이스의 "새로 만들기" 템플릿을 만들 수 없어요. 그래서 템플릿은 상태가
"템플릿"인 줄로 넣어 두었어요. 쓸 때는 그 줄을 복제(Ctrl/Cmd + D)해요. "새로 만들기 ▾" 메뉴에서 바로
고르고 싶으면 노션에서 **새로 만들기 ▾ > + 새 템플릿**을 누르고 템플릿 내용을 붙여 넣어요.
